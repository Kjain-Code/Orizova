# Ad creatives (posters)

Static ad creatives / posters for the Creative Work page go here.

1. Save the poster as WebP (or JPG), max ~1080px wide, under ~300 KB.
   Name it simply, e.g. `plot-offer-hyderabad.webp`.
2. In `src/data/work/creativeWork.js`, import it and add an entry with
   `image` (instead of `video` + `poster`) and `category: 'Ad Posters'`.
   The example is written at the top of that file.
3. Only real work, and no client name/logo on the site without permission.
