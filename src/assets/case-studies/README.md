# Case study proof screenshots

Real screenshots for /case-studies go here (Meta Ads Manager, WhatsApp chats).

Before saving:
1. BLUR the client/project name, ad account name, phone numbers, people's names and faces.
2. Keep the numbers and dates readable (results, cost per result, amount spent).
3. Save as WebP or JPG, about 1200px wide, under ~300 KB.
   Name example: `hyd-plots-ads-manager.webp`, `hyd-plots-whatsapp.webp`.

Then add them in `src/data/work/caseStudies.js` → `proof: [...]` (example in that file).
Only real screenshots — never edit the numbers in them.
