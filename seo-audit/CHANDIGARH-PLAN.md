## 4. Indexing — do this right after deploy

Google has no button that indexes all sitemap URLs at once. The sitemap tells Google what exists; Google decides what to index and when. Manual "Request indexing" allows only about 10 URLs per day. (The Google Indexing API is officially only for job-posting and livestream pages, so we don't use it.)

**Day 2 onwards:** 10 per day from Search Console → Pages → "Discovered/Crawled – currently not indexed" list.

Then check the 3 "not indexed" reasons:
- *Page with redirect* / *Alternate page with proper canonical* — normal (www, trailing slash). Ignore.
- *Discovered – currently not indexed* — Google knows the page but hasn't crawled it. Fix: internal links + backlinks + time.
- *Crawled – currently not indexed* — Google judged the page not valuable enough yet. Fix: make it more unique, add proof, add links.

What actually speeds indexing up: backlinks from sites Google already crawls (section 6), a Google Business Profile linking to the site, and sharing the URLs on LinkedIn, Facebook and Instagram.
